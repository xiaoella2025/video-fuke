视频复刻 · 起风之时 · 学员包
==============================

本包只包含《动漫视频拆解 01｜起风之时》案例。课程内容在本地浏览器运行，不上传云端，不连接课程服务器。

------------------------------------------------------------
■ 正式使用流程
------------------------------------------------------------

1. 先用老师提供的压缩包密码解压本课程包。
2. 解压后进入 qifeng-zhishi 文件夹。
3. 双击 start.bat。
4. 浏览器会打开本地课程地址：

   http://127.0.0.1:18602/web/index.html

5. 页面会显示本机机器码，格式类似：

   QIFENG-AB12-CD34-EF56

6. 点击页面上的“复制机器码”按钮。
7. 把机器码发给老师。
8. 老师使用老师端激活码工具，为你的机器码生成激活码。
9. 把老师发回的激活码完整粘贴到页面输入框，点击激活后进入课程。
10. 如果换电脑、换浏览器，或清除了浏览器本地数据，需要重新复制新的机器码发给老师生成激活码。
11. 学员不需要安装 Git。
12. 学员不需要命令行基础，只需要双击 start.bat。

------------------------------------------------------------
■ 激活码说明
------------------------------------------------------------

- 本课程使用“机器码 → 老师生成激活码 → 学员输入激活码”的正式流程。
- 机器码与当前电脑、当前浏览器本地环境绑定，别人拿到你的激活码也不能直接使用。
- 激活成功后，本浏览器会记住激活状态，刷新页面不需要重新输入。
- 清除浏览器本地数据后，页面会重新要求激活。
- 如果提示“激活码无效，或不属于当前设备”，请重新复制当前页面显示的机器码发给老师。
- 请粘贴完整激活码，中间的英文句点不要漏掉。

------------------------------------------------------------
■ 本地运行说明
------------------------------------------------------------

- 所有课程页面、案例数据、练习内容都在本地运行。
- 学员练习时上传的图片、填写的提示词等内容保存在本机浏览器数据中。
- 不需要联网。
- 不需要 Git。
- 不需要命令行基础。

------------------------------------------------------------
■ 顶部“拆解的案例视频”
------------------------------------------------------------

最终案例视频文件应命名为 case-preview.mp4，并放到：

   web/assets/cases/case-02/preview/case-preview.mp4

如果没有放入该文件，页面会显示“案例视频待上传”占位，不影响课程其他功能。

------------------------------------------------------------
■ 环境要求
------------------------------------------------------------

- Windows 10/11。

- 如果双击 start.bat 后提示找不到 Python，请安装 Python：

  https://www.python.org/downloads/

■ 常见问题
------------------------------------------------------------

Q: 双击 start.bat 后命令行一闪而过？
A: 大概率是 Python 没装，或安装时没有勾选 “Add Python to PATH”。请重新安装 Python 后再启动。

Q: 浏览器打开的是别的内容？
A: 18602 端口可能被别的程序占用。请查看 start.bat 窗口里的提示，关闭冲突程序后重新启动。

Q: 页面显示机器码，但激活码输入后进不去？
A: 常见原因有三种：
   1. 机器码复制不完整，或复制了多余空格。请重新点击“复制机器码”。
   2. 激活码粘贴不完整，漏掉了中间的英文句点。
   3. 你换了电脑、换了浏览器，或清除了浏览器本地数据，机器码已经变化。

Q: 换电脑后还能用原来的激活码吗？
A: 不能。换电脑后请复制新机器码发给老师，重新生成激活码。

Q: 学员练习上传的图、写的提示词会上传吗？
A: 不会。练习内容保存在本地浏览器中，不上传到云端。
