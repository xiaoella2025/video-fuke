视频复刻 · 起风之时 · 学员包
==============================

本包只包含《动漫视频拆解 01｜起风之时》案例。所有内容在你本地浏览器
运行，不联网、不上传云端、不接服务器。

------------------------------------------------------------
▶ 使用方法（Windows）
------------------------------------------------------------

1. 把这个文件夹整体放到一个英文路径下（避免中文路径出问题）。
2. 双击 start.bat。
3. 浏览器会自动打开本包专用地址：
       http://127.0.0.1:18602/web/index.html
4. 页面会先弹出"课程访问"密码门：
       请输入老师发给你的访问密码 → 点击"进入课程"
5. 进入后即可学习《动漫视频拆解 01｜起风之时》。
6. 用完直接关闭弹出的黑色命令行窗口，即停止服务。

学员包使用独立端口 18602，不会和常见的 8000/8080 开发端口冲突。
如果 18602 被其它程序占用，start.bat 会直接报错让你关掉冲突再启动，
绝不会把浏览器打到别的本地服务上去。

------------------------------------------------------------
▶ 密码相关
------------------------------------------------------------

- 访问密码由老师提供，请向老师获取。
- 同一浏览器输入正确密码一次后会记住，刷新页面不会再问；
  换浏览器或换电脑需要重新输入。
- 如何清除已解锁状态（重新弹密码门）：
    在课程页按 F12 打开开发者工具 → Application（应用） → Storage
    →  Local Storage → http://127.0.0.1:18602 → 删除以
    "fuke.activation.unlocked." 开头的那一条 → 刷新页面。
  或者直接在浏览器里清这个站点的全部本地数据。
- 密码错误时不会进入课程内容，只会提示"密码不正确"。

------------------------------------------------------------
▶ 顶部"拆解的案例视频"
------------------------------------------------------------

最终视频文件应命名为 case-preview.mp4 放到：

    web/assets/cases/case-02/preview/case-preview.mp4

放好后刷新页面即可播放。文件未放置时，页面会显示
"案例视频待上传"占位，并提示需要放到的路径，不会报错。

------------------------------------------------------------
▶ 环境要求
------------------------------------------------------------

- 操作系统：Windows 10/11（其它系统也可，自行用 python -m http.server）。
- Python 3：start.bat 启动本地静态服务用。
  未安装时 start.bat 会提示，安装链接：https://www.python.org/downloads/
  安装时务必勾选 "Add Python to PATH"。
- 不需要 Git。
- 不需要命令行操作。
- 不需要联网。

------------------------------------------------------------
▶ 常见问题
------------------------------------------------------------

Q: 双击 start.bat 后命令行一闪而过？
A: 大概率是 Python 没装或没勾"Add to PATH"。重新装一次。

Q: 浏览器打开是别的内容？
A: 18602 端口被别的程序占了。看 start.bat 窗口里的提示，关掉冲突再启动。

Q: 想换密码？
A: 编辑 web/activation.config.js 里的 password 字段，保存即可。
   学员需要清掉已解锁状态才会再次弹密码门（见上面"密码相关"）。

Q: 学员练习上传的图、写的提示词会丢吗？
A: 都保存在你浏览器本地（IndexedDB / localStorage），不上传任何地方。
   清空浏览器数据会丢，所以重要内容请自行备份导出。
